## 1. Introduction

### Q1. Define Artificial Intelligence (AI). Explain the four classical approaches/definitions of AI.
**Definition:**  
Artificial Intelligence (AI) is the subfield of computer science dedicated to creating computational systems capable of performing cognitive tasks that conventionally necessitate human intellect—such as visual perception, natural speech processing, heuristic decision-making, and symbolic reasoning.

**The Four Classical Approaches (Russell & Norvig Framework):**
1. **Acting Humanly (The Turing Test Approach):**
   * Proposed by Alan Turing (1950): If a human interrogator cannot distinguish whether responses are generated by a human or a computer, the machine passes the test.
   * Core capabilities required: Natural Language Processing (NLP), Knowledge Representation, Automated Reasoning, and Machine Learning.
2. **Thinking Humanly (The Cognitive Science Approach):**
   * Aims to understand and replicate human cognitive operations inside computers.
   * Leverages cognitive psychology models and neuro-imaging (fMRI) data.
3. **Thinking Rationally (The "Laws of Thought" Approach):**
   * Grounded in formal mathematical logic (Aristotelian syllogisms).
   * Limitations: Converting ambiguous real-world knowledge into strict logic is challenging; logical inference can be computationally intractable.
4. **Acting Rationally (The Rational Agent Approach - Standard Modern View):**
   * An agent is rational if it acts to achieve the best expected outcome based on its percepts and internal knowledge.
   * Focuses on correct decision-making under uncertainty rather than human fallibility.

## 2. Intelligent Agents

### Q4. Define Agent, Environment, Percept Sequence, Agent Function, and Agent Program.
* **Agent:** An entity that perceives its environment through sensors and acts upon it through actuators.
* **Percept Sequence:** The complete chronological history of everything the agent has perceived up to the current instant.
* **Agent Function ($f$):** An abstract mathematical mapping from any percept sequence to an action:
  $$f : P^* \longrightarrow A$$
* **Agent Program:** The concrete executable code running on physical hardware architecture implementing the agent function.

---

### Q5. Explain the Concept of Rationality and the PEAS Framework with an example.
**Concept of Rationality:**  
A rational agent chooses actions that maximize its expected performance measure given its percept history and built-in knowledge.  
*(Note: Rationality does not mean omniscience or perfection; it evaluates expected payoff under uncertainty).*

**PEAS Framework:**
* **P** – Performance Measure: Criteria quantifying task success.
* **E** – Environment: The external environment the agent operates in.
* **A** – Actuators: Physical/digital tools to execute actions.
* **S** – Sensors: Devices/inputs providing perceptual data.

**Example: Automated Taxi Driver:**
* **P:** Safety, speed, legal compliance, passenger comfort, maximized revenue.
* **E:** Roads, pedestrians, traffic, signals, weather.
* **A:** Steering, throttle, brakes, horn, indicators.
* **S:** LiDAR, cameras, radar, GPS, speedometer.

---

### Q6. Detail the Properties/Dimensions of Task Environments.
* **Fully vs. Partially Observable:** Complete environmental state is accessible at every point in time (Chess) vs. noisy/hidden states (Poker, Driving).
* **Deterministic vs. Stochastic:** Next state is strictly determined by current state and agent action (Chess) vs. involves probabilistic uncertainty (Driving).
* **Episodic vs. Sequential:** Current action does not affect future episodes (Defect classification) vs. current decisions impact future scenarios (Chess).
* **Static vs. Dynamic:** Environment stays unchanged while agent computes (Crossword) vs. changes continuously (Driving).
* **Discrete vs. Continuous:** States, actions, and time are countable (Chess squares) vs. continuous real values (Steering angles).
* **Single-Agent vs. Multi-Agent:** Operates alone (Solitaire) vs. interacting with competitors or collaborators (Chess, Football).

---

### Q7. Explain the Five Primary Agent Architectures.
1. **Simple Reflex Agent:** Acts strictly on current percept using Condition-Action rules (`IF status == dirty THEN suck`). Cannot handle partial observability.
2. **Model-Based Reflex Agent:** Maintains internal state to track unseen aspects of the environment based on transition and sensor models.
3. **Goal-Based Agent:** Uses explicit goal state descriptions along with planning and search to choose action sequences.
4. **Utility-Based Agent:** Uses a real-valued utility function ($U(s)$) to trade off competing goals and make rational choices under risk.
5. **Learning Agent:** Separated into:
   * *Learning Element:* Improves agent performance over time.
   * *Critic:* Evaluates behavior against external standards.
   * *Performance Element:* Selects actions in the real world.
   * *Problem Generator:* Suggests novel actions for exploration.

## 3. Solving Problems by Searching

### Q8. Formulate a search problem formally.
A search problem is formally defined by 5 components:
1. **Initial State:** $s_0 \in S$ (e.g., $In(Arad)$).
2. **Actions:** Valid actions available in state $s$: $ACTIONS(s)$.
3. **Transition Model:** Result of taking action $a$ in state $s$: $RESULT(s, a) = s'$.
4. **Goal Test:** Predicate checking if state satisfies destination criteria: $IS\_GOAL(s) \to \{True, False\}$.
5. **Path Cost:** Sum of non-negative step costs: $g(n) = \sum c(s, a, s')$.

---

### Q9. Compare Uninformed Search Strategies (BFS, DFS, UCS, DLS, IDDFS).

| Algorithm | Frontier Data Structure | Complete? | Optimal? | Time Complexity | Space Complexity |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **BFS** | FIFO Queue | Yes (if $b < \infty$) | Yes (if unit costs) | $O(b^d)$ | $O(b^d)$ |
| **DFS** | LIFO Stack | No (in $\infty$ spaces) | No | $O(b^m)$ | $O(bm)$ |
| **UCS** | Priority Queue (by $g(n)$) | Yes (if step cost $\ge \epsilon$) | Yes (Cost-optimal) | $O(b^{1 + \lfloor C^* / \epsilon \rfloor})$ | $O(b^{1 + \lfloor C^* / \epsilon \rfloor})$ |
| **DLS** | LIFO Stack (limit $l$) | No (if $l < d$) | No | $O(b^l)$ | $O(bl)$ |
| **IDDFS** | Iterative LIFO Stack | Yes (if $b < \infty$) | Yes (if unit costs) | $O(b^d)$ | $O(bd)$ |

*($b$ = branching factor, $d$ = depth of shallowest goal, $m$ = max tree depth).*

### Q10. Explain A* Search, Admissibility, and Consistency of Heuristics.
**A* Evaluation Function:**
$$f(n) = g(n) + h(n)$$
* $g(n)$: Exact path cost from initial node to node $n$.
* $h(n)$: Estimated cost from node $n$ to goal.
* $f(n)$: Estimated total cost of cheapest solution passing through $n$.

**Conditions for Optimality:**
1. **Admissibility (Tree Search):** Heuristic $h(n)$ never overestimates true cost to goal:
   $$0 \le h(n) \le h^*(n)$$
2. **Consistency / Monotonicity (Graph Search):** For every node $n$ and successor $n'$ via action $a$:
   $$h(n) \le c(n, a, n') + h(n')$$
   Consistent heuristics satisfy the triangle inequality and guarantee A* finds the optimal path without re-expanding closed nodes.

## 4. Quantifying Uncertainty

### Q11. Explain Full Joint Distributions and Bayes' Rule.
* **Full Joint Distribution (FJD):** Assigns probabilities to every atomic event in the state space.
  * Marginalization: $P(Y) = \sum_z P(Y, Z = z)$.
  * Drawback: For $n$ boolean variables, requires $2^n - 1$ entries, which is computationally intractable for large domains.
* **Bayes' Rule Formulation:**
  $$P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)}$$
  In diagnostic reasoning:
  $$P(Cause \mid Effect) = \frac{P(Effect \mid Cause) \cdot P(Cause)}{P(Effect)}$$

---

### Q12. Explain the Naive Bayes Classifier model.
**Core Assumption:** Features $X_1, X_2, \dots, X_n$ are conditionally independent given class variable $C$:
$$P(X_1, X_2, \dots, X_n \mid C) = \prod_{i=1}^n P(X_i \mid C)$$
**Classification Decision Rule:**
$$C^* = \arg\max_{c} \left[ P(C = c) \prod_{i=1}^n P(X_i = x_i \mid C = c) \right]$$

## 5. Probabilistic Reasoning

### Q13. Define Bayesian Networks and the Chain Rule.
A Bayesian Network is a Directed Acyclic Graph (DAG) representing conditional dependencies among random variables.
* **Nodes:** Random variables.
* **Directed Edges:** Direct probabilistic influences.
* **Conditional Probability Tables (CPTs):** Specifies $P(X_i \mid Parents(X_i))$ at each node.
* **The Chain Rule:**
  $$P(X_1, X_2, \dots, X_n) = \prod_{i=1}^n P(X_i \mid Parents(X_i))$$

---

### Q14. Compare Exact vs. Approximate Inference in Bayesian Networks.
* **Exact Inference:**
  * *Enumeration:* Evaluates sums of conditional probability products over unobserved variables ($O(2^n)$ runtime).
  * *Variable Elimination:* Dynamic programming caching intermediate factors. Exact inference is NP-hard in general networks.
* **Approximate Inference (Monte Carlo Methods):**
  * *Rejection Sampling:* Rejects samples inconsistent with evidence.
  * *Likelihood Weighting:* Weights samples by likelihood of observed evidence.
  * *MCMC (Gibbs Sampling):* Random walk sampling conditioned on Markov blanket.

## 1. Learning from Examples & The ML Landscape

### Q15. Define Machine Learning and its Core Classifications.
**Definitions:**
* **Arthur Samuel (1959):** "Field of study that gives computers the ability to learn without being explicitly programmed."
* **Tom Mitchell (1997):** "A program learns from experience $E$ regarding task $T$ and performance $P$ if performance on $T$ improves with experience $E$."

**Types of ML Systems:**
* **Supervised Learning:** Labeled data $(x_i, y_i)$. Tasks: Classification (discrete) and Regression (continuous).
* **Unsupervised Learning:** Unlabeled data $\{x_i\}$. Tasks: Clustering, Dimensionality Reduction, Anomaly Detection.
* **Batch vs. Online:** Batch trains offline on all data at once; Online trains incrementally on data streams.
* **Instance-Based vs. Model-Based:** Instance-based memorizes data points ($k$-NN); Model-based fits parameters to a parameterized function (Linear Regression, Neural Nets).

---

### Q16. Detail the Major Challenges and Pitfalls in Machine Learning.
1. **Insufficient Training Data:** High-capacity algorithms require large datasets to generalize.
2. **Nonrepresentative Data (Sampling Bias):** Dataset does not mirror actual deployment conditions.
3. **Poor Data Quality:** Noise, missing values, outliers distort model fit.
4. **Irrelevant Features:** Solved via feature selection and feature extraction.
5. **Overfitting:** Model fits noise in training data. High training accuracy, poor testing accuracy. Remediated via regularization, pruning, cross-validation.
6. **Underfitting:** Model is too simple to capture patterns. High training error and high test error. Remediated via more expressive models and better features.

## 2. Classification & Evaluation Metrics

### Q17. Explain the Confusion Matrix, Accuracy, Precision, Recall, and F1-Score.

| Metric | Formula | Practical Meaning |
| :--- | :--- | :--- |
| **Accuracy** | $\frac{TP + TN}{TP + TN + FP + FN}$ | Overall correct fraction (misleading under class imbalance). |
| **Precision** | $\frac{TP}{TP + FP}$ | Fraction of positive predictions that are truly positive. |
| **Recall (Sensitivity)** | $\frac{TP}{TP + FN}$ | Fraction of actual positive cases correctly identified. |
| **F1-Score** | $2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}$ | Harmonic mean balancing precision and recall. |

---

### Q18. Explain the Precision/Recall Tradeoff and the ROC-AUC Curve.
* **Tradeoff:** Raising classification threshold increases precision but lowers recall, and vice-versa.
* **ROC Curve:** Plots True Positive Rate (Recall) vs. False Positive Rate ($FPR = \frac{FP}{FP + TN}$).
* **AUC (Area Under Curve):** Measures ranking performance across all thresholds (0.5 = random guess, 1.0 = perfect classifier).

---

### Q19. Differentiate Multiclass, Multilabel, and Multioutput Classification.
* **Multiclass:** Each instance belongs to exactly one out of $K > 2$ classes (e.g., MNIST digit $0-9$).
* **Multilabel:** Each instance can belong to multiple binary labels simultaneously (e.g., detecting Alice AND Bob in a photo).
* **Multioutput:** Each instance has multiple outputs, and each output can take multiple class values (e.g., removing pixel noise).

## 3. Decision Trees

### Q20. Explain the CART Algorithm and Compare Gini Impurity vs. Entropy.
**CART (Classification and Regression Trees):** Splits nodes using binary partitions that minimize weighted impurity:
$$J(k, t_k) = \frac{m_{left}}{m} G_{left} + \frac{m_{right}}{m} G_{right}$$

**Impurity Measures:**
* **Gini Impurity:** 
  $$G = 1 - \sum_{k=1}^n p_k^2$$
* **Entropy:** 
  $$H = - \sum_{k=1}^n p_k \log_2(p_k)$$
* *Comparison:* Gini is slightly faster computationally (avoids logs); Entropy produces slightly more balanced trees. Both yield near-identical trees in practice.

**Regularization Hyperparameters:** `max_depth`, `min_samples_split`, `min_samples_leaf`, `max_leaf_nodes` prevent overfitting.

## 4. Philosophy, Ethics, and Safety of AI

### Q21. Can Machines Really Think? Explain Weak vs. Strong AI and the Chinese Room Argument.
* **Weak AI:** Simulates intelligent behavior for specific tasks without consciousness.
* **Strong AI (AGI):** Possesses general human-like reasoning, consciousness, and genuine understanding.
* **Searle's Chinese Room Argument (1980):** A person inside a room manipulates Chinese symbols using English rulebooks without understanding Chinese. Conclusion: Syntax (running programs) does not produce Semantics (true comprehension), arguing against Strong AI claims based purely on behavioral tests.

---

### Q22. Explain the Key Ethical and Safety Challenges in Modern AI.
1. **Algorithmic Bias:** Systems encoding and amplifying historical biases (in hiring, bail decisions, credit scoring).
2. **Explainability (XAI):** Black-box decisions in healthcare and criminal justice require interpretability.
3. **Privacy and Surveillance:** Unauthorized mass data harvesting and facial recognition tracking.
4. **Lethal Autonomous Weapons (LAWS):** Ethical issues around automated life-or-death decisions without human agency.
5. **AI Safety and Alignment:** Aligning superintelligent agent objectives with human survival and values, preventing reward hacking and catastrophic goal misalignment.
